# hx-math
Vector, Matrix, and Math library for 4D, 3D, and 2D Computer Graphics

## Data types
### Vector
- vec5f, vec5i
- vec4f, vec4i, vec4u
- vec3f, vec3u
- vec2f, vec2i, vec2u

### Matrix
- Mat5
- Mat4
- Mat3

### Axis-Aligned Bounding Box
- aabb4 (float)
- aabb4i
- aabb3

### Rotors
- rotor4
